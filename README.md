This repository is now archived and no longer maintained.

However, Rebaslight lives on! Starting with version 3.8.0, it is now a closed source and is available to be used at [rebaslight.com](https://www.rebaslight.com)

It no longer uses electron and now runs fully in the web browser using the [WebCodecs API](https://developer.mozilla.org/en-US/docs/Web/API/WebCodecs_API) via the excellent [mediabunny](https://mediabunny.dev/) library.
